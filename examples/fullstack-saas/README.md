- Auth (NextAuth / Clerk / Lucia — pick one).

- `CLAUDE.md` + `.cursor/rules/*` + `AGENTS.md` adapters installed.
- `.obsidian-ai-memory/` seeded with realistic project context, a few session digests, an error memory entry, and an ADR.
