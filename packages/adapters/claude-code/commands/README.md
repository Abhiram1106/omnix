# Claude Code slash commands

This directory is intended for `.claude/commands/*.md` slash command definitions copied into a project.

Suggested commands the CLI may install:

- `/retrieve-context` — read all relevant vault files and summarize.
- `/session-digest` — produce a digest of the current session.
- `/error-memory` — interactively log a new error entry.
- `/onboard` — run the project-onboarding workflow.

Commands are plain markdown with optional frontmatter. See the Claude Code docs for the current schema.
