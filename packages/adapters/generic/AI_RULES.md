# AI_RULES.md — Universal compact rules

> A shorter sibling to `AGENTS.md`. Drop into projects whose AI tool expects a file named `AI_RULES.md`.

1. Retrieve memory from `.obsidian-ai-memory/` before working (`02-PROJECTS/`, `01-SESSIONS/`, `03-ERRORS/`, `04-DECISIONS/`, `07-LESSONS/`).
2. Follow existing project conventions.
3. Never repeat a known error.
4. Update memory after meaningful work — session digest mandatory.
5. Update docs when behavior or setup changes.
6. Ask before destructive commands.
7. Never expose secrets.
8. Verify before claiming completion.
9. Prefer small safe changes.
10. Record assumptions and open questions in the digest.

See `AGENTS.md` for the full loop and `packages/core/standards/*` for engineering rules.
