# @omnix/core

The source-of-truth content. Plain markdown, no code.

- `standards/` — engineering rules every adapter must respect.
- `workflows/` — end-to-end procedures (onboarding, feature build, bug fix, etc.).
- `agents/` — minimal role definitions any tool can mount.
- `templates/` — ADR, PRD, runbook, postmortem, AI rules, etc.

Adapters reference these files; they do not duplicate them.
