# 01-SESSIONS

Session digests. **Every meaningful AI session writes one here.**

## Layout

```
01-SESSIONS/
  YYYY-MM-DD/
    session-HHMM-<tool>.md
```

Examples:
- `2026-05-14/session-0915-claude-code.md`
- `2026-05-14/session-1130-cursor.md`
- `2026-05-14/session-1645-aider.md`

## Template

See `../templates/session-digest.md`.

## How AI tools use this

- Pre-work: read the **last 3-5** session files.
- Post-work: write a new file using the digest template.
