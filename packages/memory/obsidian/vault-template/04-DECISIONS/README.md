# 04-DECISIONS

Architectural and product decisions.

## Files

- `adr-index.md` — index of ADRs (`adr-NNNN-*.md` files, also lived here or in repo `docs/adr/`).
- `decisions.md` — lighter-weight decision entries (everything that isn't ADR-worthy but matters).

## Template

`../templates/decision-entry.md`.

## How AI tools use this

- Pre-work: skim `decisions.md` and read any ADR referenced by current work.
- Post-work: every non-trivial decision gets an entry. Architectural ones get an ADR too.
