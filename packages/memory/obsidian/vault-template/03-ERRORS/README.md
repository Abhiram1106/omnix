# 03-ERRORS

Error memory. **Every fixed error becomes a prevention rule here.**

## Files

- `error-memory.md` — log of fixed errors with prevention rules.
- `known-issues.md` — open issues not yet fixed (workarounds, status).
- `anti-patterns.md` — patterns to never repeat in this project.

## Template

`../templates/error-entry.md`.

## How AI tools use this

- Pre-work: skim before designing or fixing — never repeat a known error.
- Post-work: every fixed bug gets a new entry.
