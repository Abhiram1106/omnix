# Decision Entry — Schema

Lightweight decision record. Lives in `04-DECISIONS/decisions.md` (one section per decision) or as `decision-NNNN.md` files. Architectural decisions promote to an ADR (see `templates/adr-template.md`).

## Fields

| Field | Required | Type | Notes |
|---|---|---|---|
| Date | yes | YYYY-MM-DD | |
| Decision | yes | one-line summary | |
| Context | yes | text | forces in play, problem being solved |
| Options Considered | yes | list | each with one-line summary |
| Final Choice | yes | reference to one of the options | |
| Why | yes | text | the reasoning |
| Tradeoffs | yes | text | what we're giving up |
| Follow-up Required | yes | list | tasks generated by this decision |

## Promotion to ADR

Promote to a full ADR when:
- The decision is hard to reverse.
- It affects multiple modules or services.
- It introduces a new dependency or external system.
- A future engineer would benefit from the longer-form rationale.
